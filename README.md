# Triplex

A small C++ terminal puzzle. Each level gives the sum and product of three numbers. Enter a combination that matches both clues to unlock the next stage of the fictional heist.

## Run

From the repository root, compile [triplex.cpp](triplex.cpp) with a C++ compiler. For example, with GCC:

```sh
g++ -std=c++11 triplex.cpp -o triplex
./triplex
```

Enter three integers separated by spaces when prompted.
